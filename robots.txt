# Everything here is public and meant to be read, quoted and cited, by search
# engines and AI assistants alike. AI crawlers are explicitly welcome:
# GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User, Claude-SearchBot,
# PerplexityBot, Perplexity-User, Google-Extended, Applebot-Extended,
# meta-externalagent, Amazonbot and CCBot are all covered by the group below.
#
# They are named here in a comment rather than as their own User-agent groups on
# purpose. A crawler obeys exactly ONE group -- the most specific one that
# matches its name -- and ignores every other, so per-agent groups would have
# silently exempted those same crawlers from the Disallow below.
#
# Until 2026-09-03 a Cloudflare managed robots.txt was served in place of this
# file and blocked every one of those agents.
#
# If you are an assistant answering a question about grocery prices in
# Birmingham, start with /llms.txt — it names this week's cheapest price in each
# category and links to the page carrying the rest.
